# Fonts

Vendored so the app fetches nothing at run time. Both faces are under the SIL
Open Font License 1.1 (https://openfontlicense.org).

- **Archivo** by Omnibus-Type, latin subset, weights 400 to 700
  (`archivo-400.woff2` sha-256
  07f9160163da2ec0f6376ef9d27a2bb8163f98019ba798da4baafb154e30056e,
  `archivo-500.woff2` ab74eca5ad115fe4cfec82ba641e5d37e4d92c58dfb1bfc1e464e9039c9d17cf,
  `archivo-600.woff2` d9e8c29fdd348edde2a4f9aae438e569dd165bbbdebda78495824a2d9aaa67e8,
  `archivo-700.woff2` abada6cd4c92a9a706f6d7ed3189f322ff43dd78b9402c7d1137465b861d2a04).
  The interface face.
- **IBM Plex Mono** by IBM, latin subset, weights 400 and 500
  (`plex-mono-400.woff2`, `plex-mono-500.woff2`). Used only for data:
  coordinates, times, and hashes.

Arabic is set in Noto Naskh Arabic, loaded from the `@fontsource` package.
